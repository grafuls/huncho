# Huncho — Brand Mark

A minimalist monoline logo mark for **Huncho** — someone who runs decision models,
and whose name also leans on "hunk."

## Concept

**The Huncho H.**

Two strong vertical pillars joined by a single smooth crossbar that rises into a
gentle peak. It reads as the Huncho monogram, while the arch carries the meaning:

- **Two bold pillars** → strength, broad-shouldered confidence ("hunk").
- **Rising crossbar → a single summit** → a decision point / the peak a path reaches.
- **One continuous monoline, uniform stroke, flat color, no fill** → decision
  models, clarity, and a clean vector brand mark.

A single flat accent color — deep navy `#1B2A4A` — on pure white. No gradients,
no shading, no textures, no text.

## Usage

- The mark is a single color (`#1B2A4A`), so it also works inverted (white on navy)
  and as a one-color stamp.
- Full vector source is `logo.svg` — scale it to any size without losing quality.
- Stroke weight is 42 on a 400×400 canvas (~10.5%) for a bold, uniform monoline.
- Maintain generous padding; the mark was designed to read at favicon size (16 px).
